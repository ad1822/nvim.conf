# Keybindings for Nvim




## **LazyVim Keybinds Notes**

### **Navigation**

* `Alt + j` — Move Down
* `Alt + k` — Move Up
* `Shift + H` — Move to previous Tab / Buffer
* `Shift + L` — Move to next Tab / Buffer
* `[b` — Next Tab
* `]b` — Previous Tab

---

### **Buffer / Tab Management**

* `<leader>bD` — Close Tab / Buffer
* `<leader>bp` — Pin the Buffer

---

### **Search & Results Navigation**

* `n` — Next Result
* `N` — Previous Result
* `[[` — Next References — **GOOD**
* `]]` — Previous References — **GOOD**
* `Alt + N` — Next References — **GOOD**
* `Alt + P` — Previous References — **GOOD**

---

### **File Operations**

* `Ctrl + S` — Save the file
* `<leader>fn` — New File

---

### **Line Numbers & UI**

* `<leader>uL` — Toggle Relative Number
* `<leader>ul` — Toggle Line Number
* `<leader>uD` — Toggle Dimming — **GOOD**
* `<leader>uh` — Toggle Inlay Hints
* `<leader>uz` — Toggle Zen Mode — **GOOD**

---

### **Session Management**

* `<leader>ql` — Restore Session — **GOOD**
* `<leader>qd` — Don't save current Session — **GOOD**

---

### **Quitting**

* `<leader>qq` — Quit All — **GOOD for Quit**

---

### **Terminal**

* `<leader>fT` — Terminal
* `<leader>` `Ctrl + /` — Toggle Terminal — **GOOD**

---

### **Window Management**

* `<leader>|` — Split Window Right
* `<leader>wd` — Kill that window

---

### **LSP**

* `<leader>gd` — Go to Definition — **GOOD**
* `<leader>gr` — References — **GOOD**
* `Shift + K` — Hover — **GOOD**

---

### **Comments**

* `gc0` — Add Comment

---

### **Search & Replace**

* `<leader>sr` — Search And Replace — **GOOD**

---

### **Mason**

* `<leader>cm` — Mason — **GOOD**

---

### **File Finder / Search**

* `<leader><SPACE>` — Find Files — **GOOD**
* `<leader>,` — Search through Buffers — **GOOD**
* `<leader>/` — Find Words — **GOOD**
* `<leader>:` — Command History — **GOOD**
* `<leader>e` — File Explorer — **GOOD**
* `<leader>fp` — Find Projects — **GOOD**
* `<leader>fr` — Recent Files — **GOOD**

---

### **Git**

* `<leader>gd` — Git Diff — **GOOD**
* `<leader>gs` — Git Status — **GOOD**

---

### **Notifications & Help**
